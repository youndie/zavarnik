# B-03 — JDK 26 на Linux-машине: ZGC и JDK-8377932 прогоном

Ресёрч знает про JDK 26 две вещи по исходникам: JEP 516 разрешает ZGC, а исправление
JDK-8377932 попало только в 26.0.2 (§1.2). Ни та, ни другая не проверена запуском — на маке и на
Linux-машине стоит только 25. Плагин будет принимать решения по номеру версии тулчейна, и
граница должна быть измерена, а не вычитана.

- **Решение: поставить 26.0.2.1 (GA на jdk.java.net) в `/usr/lib/jvm` на Linux-машине и прогнать
  `experiments/aot-validation/run.sh`** — журнал ложится рядом с тремя существующими.
- Дополнительно один прогон 26.0.1, если сборка доступна: он должен показать принятый устаревший
  jar (R3/R4 с `shared>0`), иначе граница в ресёрче неверна.
- Не покрывает: замер Ktor на 26 — это повтор [B-01](B-01-ktor-stand-and-readiness-timing.md)
  после установки.

- AC: `experiments/aot-validation/results/` содержит журнал с `openjdk-26`; ресёрч §1.1 (ZGC) и
  §1.2 (граница исправления) ссылаются на него.
- Якоря: `experiments/aot-validation/run.sh`, `experiments/aot-validation/results/`.
