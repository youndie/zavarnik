# B-02 — Доля классов Kotlin-приложения, пришедших из кэша (RQ4)

> **Сделано 06.09.2026.** На образце `samples/ktor` (флаг `-PlambdasClass` в его сборке):
> indy — 269 hidden lambda-прокси загружено, 269 из кэша, 2262 из 2262 jar-классов;
> `-Xlambdas=class` — 265 прокси (библиотечные), все из кэша, 2264 из 2264. Разницы нет, флаг
> компилятора документировать не нужно; RQ4 закрыт, риск 4 снят (ресёрч §1.8).

С Kotlin 2.0 лямбды компилируются через `invokedynamic` (ресёрч §1.8), то есть в hidden-классы,
которые Leyden архивирует с оговорками («Hidden class complexity» в заметке о тренировочных
прогонах). Машины состояний корутин и сериализаторы `kotlinx.serialization` — обычные классы, но
это надо увидеть в журнале, а не предположить.

- **Решение: считать по `-Xlog:class+load`, отношение `source: shared objects file` к общему
  числу классов приложения** — тот же счётчик, что использует `aotVerify`
  ([B-06](B-06-aot-verify-task.md)), чтобы стенд и плагин смотрели одним глазом.
- Сравнить `-Xlambdas=indy` (умолчание) с `-Xlambdas=class`.
- Не покрывает: оптимизацию самих библиотек; результат — флаги компилятора в документации плагина
  или запись «разницы нет».

- AC: таблица в ресёрче, §1.8: доля классов из кэша для двух режимов лямбд, с числом классов.
- Якоря: `experiments/aot-validation/run.sh` (функция `summ` — тот же подсчёт),
  `docs/research/research-architecture.md`.
